# Vicious — sitio web

Plantilla responsive en HTML y CSS inspirada en la referencia proporcionada.

## Uso
Abre `index.html` en un navegador. No requiere instalación ni JavaScript.
Las imágenes extraídas de la referencia están en `assets/`.

## Personalización
- Edita textos y enlaces en `index.html`.
- Cambia colores, tipografías y distribución en `styles.css`.
- Sustituye las imágenes de `assets/` por fotografías de producto propias cuando estén disponibles.

Nota: las fuentes se cargan desde Google Fonts; si no hay conexión, se usan fuentes de respaldo.
